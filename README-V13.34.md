# V13.34 — Editar o crear otra ruta

- Después de optimizar se mantiene el modo limpio.
- Se muestra **Iniciar recorrido** y un botón secundario **Modificar / crear otra ruta**.
- El botón secundario restaura la sección de ubicaciones y permite agregar, eliminar o limpiar puntos antes de volver a optimizar.
- No modifica Apps Script.
