# Rutas de Inspección V13.58

Corrección puntual del buscador del mapa general.

- Una consulta formada solo por números busca únicamente en el código de subestación.
- Se excluyen ID internos, latitud y longitud del filtro.
- Consultas alfanuméricas buscan en subestación, alimentador, dirección y técnico.
- Se conserva la persistencia y funcionamiento de mapas de V13.57.
