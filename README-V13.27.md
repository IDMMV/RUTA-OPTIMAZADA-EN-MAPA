# Rutas de Inspección V13.27

## Corrección principal

Esta versión conserva las dos funciones por separado:

- **Formulario existente:** abre Microsoft Forms.
- **Inspección MT:** abre el nuevo formulario interno con registro fotográfico guiado y hasta 20 fotos.
- **Ver reportes:** consulta los informes y fotografías guardados para la subestación.

Las tres acciones aparecen en:

- Tarjetas de la ruta optimizada.
- Resultados del buscador de subestaciones.
- Marcadores del planificador.
- Marcadores del Mapa general.

También se mantiene Cambiar estado, Google Maps, Compartir y Editar ubicación.

## Instalación

Sube todos los archivos a GitHub. Para esta corrección no es necesario modificar Apps Script si ya instalaste el de V13.26.
