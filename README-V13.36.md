# V13.36 — Retorno a la tarjeta en pantalla completa

- Al cerrar Formulario existente, Inspección MT, Ver reportes o Cambiar estado, la aplicación conserva/restaura la pantalla completa.
- La misma tarjeta del punto vuelve a abrirse automáticamente.
- El usuario puede elegir otra acción sin buscar de nuevo el marcador.
- También se restaura la tarjeta después de guardar una inspección o un cambio de estado.
