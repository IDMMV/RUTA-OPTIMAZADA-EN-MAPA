# V13.15 – Mapa compacto

Esta versión añade un botón ▣ dentro del mapa. Al pulsarlo, el mapa se convierte en una miniatura flotante dentro de la aplicación. El botón cambia a ✕ para restaurar el mapa.

La miniatura mantiene ubicación, ruta, zoom, centrado y datos de la parada activa. No puede mostrarse encima de otras aplicaciones Android; para eso se requerirá una app nativa con Picture-in-Picture.

Para actualizar GitHub, reemplaza index.html y service-worker.js. Conserva tu config.js actual con la URL de Apps Script.
