# V13.25 — Usuarios y controles de zoom

## Crear usuarios
1. Inicia sesión con una cuenta Administrador.
2. Abre la pestaña **Usuarios**.
3. Completa Usuario, Nombre completo, PIN, Rol y Técnico.
4. Pulsa **Crear usuario** y luego **Actualizar**.

## Mapa general
Se añadieron controles visibles dentro del mapa:
- `+` acercar.
- `−` alejar.
- `◎` encuadrar todos los puntos filtrados.
