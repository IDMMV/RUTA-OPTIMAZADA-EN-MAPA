# Rutas de Inspección V13.26

## Nuevo módulo integrado
- Formulario breve de inspección MT.
- Nivel de tensión visible.
- Registro fotográfico guiado por 11 categorías.
- Hasta 20 fotografías comprimidas.
- Galería y revisión antes de guardar.
- Reportes asociados a cada subestación.
- Fotos almacenadas en Google Drive y datos en Google Sheets.

## Instalación
1. Reemplazar `Code.gs` por `apps-script.gs`.
2. Ejecutar `initializeDatabase`.
3. Implementar una nueva versión de Apps Script.
4. Subir todos los archivos a GitHub Pages.
5. Verificar que `config.js` conserve la URL `/exec`.
